# Chương 13 — Code mẫu: Class & Object

```
javac *.java
java Main
```

`SinhVien.java` định nghĩa class (khuôn mẫu) với field, hai constructor (không tham số và có tham
số), và các phương thức instance. `Main.java` tạo nhiều object `SinhVien` độc lập từ cùng một class,
minh hoạ mỗi object tự mang dữ liệu riêng — sửa object này không ảnh hưởng object khác dù cùng
class.
