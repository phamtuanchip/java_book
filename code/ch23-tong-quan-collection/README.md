# Chương 23 — Code mẫu: tổng quan Collection Framework

```
javac CollectionOverviewDemo.java
java CollectionOverviewDemo
```

Xem lướt qua 4 cấu trúc dữ liệu chính: `List` (có thứ tự, cho trùng lặp), `Set` (không trùng lặp),
`Map` (cặp key-value), `Queue` (FIFO). Chương này chỉ giới thiệu tổng quan — mỗi cấu trúc sẽ có
chương riêng đi sâu (Chương 24-26).
